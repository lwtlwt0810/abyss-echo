# 《深渊回响》玩法规格说明（v2.0 · 扩量版）

> 原创俯视角地牢射击 Roguelike。品类框架参考（双摇杆射击 + 房间推进），角色、武器、敌人、Boss、遗物、数值、美术与音效全部为本项目原创设计。
> 文中所有数值均为自定值并标注设计意图；`index.html` 内的数据表与本表一一对应。

---

## 1. 产品定位与边界

| 项目 | 定义 |
| --- | --- |
| 品类 | 俯视角双摇杆射击 + 房间制地牢 Roguelike |
| 单局时长 | 25–40 分钟（5 层 + 可选隐藏层） |
| 目标平台 | HTML5 单文件（桌面 / 移动浏览器）→ 安卓安装包 |
| 商业模式 | 无内购、无广告、无联网；13 角色 / 59 武器 / 40 遗物默认全部解锁 |
| 操作 | 触屏双摇杆、键鼠两套，自动识别，可混用 |
| 美术 | 全部 Canvas 代码实时绘制（多边形 / 渐变 / 光效 / 粒子），无外部图片 |
| 音频 | 全部 WebAudio 程序化合成（振荡器 + 噪声 + 滤波器），无音频文件 |
| 存档 | localStorage；局外成长永久保存，单局进度不保存 |
| 原创性 | 不引用任何商业 APK 的代码、资源或数据；不使用任何现成素材文件 |

### 设计支柱

1. **三秒上手**：左摇杆走、右摇杆打；其余系统都可以不看说明直接玩。
2. **每一枪都有回声**：后坐、命中停顿、闪白、震屏、伤害数字五件套。
3. **房间是节拍器**：清房 → 开门 → 选路线（精英 / 宝箱 / 商店 / 事件）→ Boss。
4. **构筑而非运气**：双武器槽 + 被动 + 主动 + 遗物联动，同角色能玩出不同流派。
5. **数量必须有差异**：每个新增武器/敌人/Boss 都有独立手感或行为参数，不做换皮。

## 2. 核心循环

```
标题 → 局外解锁树 → 选角色（13）
  → 第 1 层（12 房）
  → 房间：普通 / 精英 / 宝箱（三选一遗物）/ 商店 / 事件
  → 清波次 → 开门 → 小地图选下一间
  → 层 Boss（锁门、多阶段）
  → 传送门 → 下一层（保留武器与遗物，回复 25% 最大生命）
  → 第 5 层 Boss
      ├─ 无隐藏条件：结算（金币入账 / 统计 / 威胁等级 +1）
      └─ 持有 ≥3 枚「回响碎片」：开启隐藏层「回响之间」
            → 6 房 → Boss「回响守卫」→ 隐藏 Boss「回响原型」→ 真结局结算
```

失败（HP ≤ 0）→ 死亡结算 → 本局金币 100% 折算局外货币 → 回标题。
单局内不保存；退出即放弃本局。

**节奏意图**：普通房 2–3 波，单房 20–40 秒；精英房 35–55 秒；Boss 70–150 秒。单层 8–12 分钟。

## 3. 输入与操作

### 3.1 触屏（双摇杆）

| 区域 | 行为 |
| --- | --- |
| 屏幕左 45% 按下 | 生成浮动左摇杆（基准=按下点），拖动移动；半径 70 px，死区 8%，位移 ≥70% 即满速 |
| 屏幕右 45% 按下 | 生成浮动右摇杆，拖动瞄准并**持续开火**，松手停火 |
| 右下技能钮（r=46） | 主动技能，显示冷却环与剩余秒数 |
| 左下武器钮（r=34） | 切换武器槽 1 / 2 |
| 左侧遗物条 | 显示已获遗物图标（点击查看名称） |
| 右上暂停钮（r=26） | 暂停菜单（位于小地图下方，避免重叠） |

摇杆方向经 5 帧滑动平均（≈83 ms）；触屏瞄准在 ±8° 内存在敌人时微吸附（可关）。

每层房间构成（保底）：起点 ×1、Boss ×1、精英 ×1、宝箱 ×1、商店 ×1、事件 ×1，其余普通战斗房。
隐藏层无商店，宝箱 ×2、精英 ×1、普通 ×2、Boss ×1（守卫），守卫死后原地开启「回响之门」进入原型 Boss 场。

### 5.2 生成算法（随机游走 + BFS）

1. 起点固定为网格中心。
2. 随机游走扩张：从已有房间随机取一个，再随机取一个未占用的四邻格加入，直到达到目标房间数；保证四连通。
3. 对起点 BFS，取距离最远的房间为 Boss 房（同距离随机）。
4. 死胡同（度数 1）按优先级分配：精英 → 宝箱 → 商店 → 事件；不足时从度数 2 的房间中补。
5. 每层使用 `seedBase + floor*977 + run.seed` 派生，同局可复现。
6. 门由房间邻接推导；进房时门关闭，清空后解锁；Boss 房门永久锁到 Boss 死亡。

### 5.3 房间内容

| 类型 | 内容 | 奖励 |
| --- | --- | --- |
| 普通 | 2–3 波敌人，每波 3–6 只，至少 1 远程 | 金币 6–14、少量血/能量 |
| 精英 | 1 只带 1–2 条词缀的精英 + 2–3 小怪 | 必掉遗物 + 金币 20–30 |

| Boss | 锁门，Boss 多阶段 | 大量金币 + 回响碎片概率 + 传送门 |

## 6. 战斗通用规则

| 参数 | 数值 | 设计意图 |
| --- | --- | --- |
| 玩家半径 | 15 px | 与 32 px 墙厚、6–10 px 敌弹形成可读的擦弹空间 |
| 玩家基础移速 | 250 px/s | 略快于多数敌人，保证走位是主要防御手段 |
| 基础生命 | 120 | 可承受约 10–14 次杂兵伤害 |
| 基础能量 | 100，回复 18/s | 激光/蓄力武器靠能量形成节奏 |
| 无敌帧 | 0.8 s（受击后） | 防止弹幕瞬间连击致死 |
| 受击硬直 | 0.12 s | 有反馈但不失控 |
| 击退 | 180 px/s，0.16 s 衰减 | 受击位移可感知 |
| 暴击 | 基础 5%，倍率 ×1.8 | 与遗物/局外树形成成长空间 |
| 命中停顿 | 普通 0.03 s / 暴击 0.045 s / 击杀 0.06 s / Boss 阶段转换 0.12 s | 打击感来源；按敌人节流，避免机枪把游戏冻住 |
| 敌人闪白 | 0.08 s | 命中确认 |
| 拾取吸附 | 110 px，吸附速度 420 px/s | 减少捡垃圾的烦躁 |
| 接触伤害 | 每 0.6 s 一次 | 防止贴脸秒杀 |

**伤害公式**

```
最终伤害 = 武器伤害 × 角色/遗物/局外伤害乘区 × 暴击(×1.8) × 敌人易伤 × 距离/条件加成
敌人受伤 = 最终伤害 × 护甲减伤 × 护盾正面减免
玩家受伤 = 敌人伤害 × (1 - 护甲%) × (1 - 护盾吸收)
```

**敌人成长**

```
层倍率：HP ×(1 + 0.55 × floor)，伤害 ×(1 + 0.22 × floor)
威胁等级（局外）：HP ×(1 + 0.12 × threat)，伤害 ×(1 + 0.08 × threat)
```

**能量**

- 激光/火焰/蓄力武器消耗能量：激光 6/s，火焰 5/s，蓄力按蓄力时间 8–20。
- 能量不足时武器无法开火（提示「能量不足」），平A武器不耗能。

## 11. Boss（6 + 1 隐藏）

> 所有 Boss：进场 1.2 s 无敌演出 → 分阶段；阶段转换有 0.4 s 硬直与震屏。每个招式都有 ≥0.45 s 的预警（地面圈/射线/线框）。

### 11.1 黏液之王（第 1 层）

- HP 760 / 半径 54 / 接触伤害 16
- 阶段 1（100%–50%）：跳跃砸地（预警圈 90）→ 落地 8 发环形弹；每 2 次跳跃召唤 2 只小黏团。
- 阶段 2（50%–0）：体型 ×1.15，滚动冲撞（撞墙反弹 2 次），每 4 s 发射 12 发螺旋弹。
- 节奏：慢速重击，教会玩家看预警。

### 11.2 齿轮监工（第 2 层）

- HP 1250 / 半径 58 / 接触伤害 18
- 阶段 1：钻头冲锋 ×3（每次带 0.5 s 蓄力）→ 部署 2 座哨戒炮。
- 阶段 2：旋转激光扫射 2.4 s（两条反向光束），结束后齿轮环爆 16 发。
- 节奏：追击 + 场地控制。

### 11.3 霜喉（第 3 层）

- HP 1750 / 半径 60 / 接触伤害 18
- 阶段 1：冰霜吐息锥（持续 1.6 s，减速）→ 冰锥雨（6 个落点，延迟 0.9 s）。
- 阶段 2：地面冻结区域 3 块（持续 5 s，踩上减速 50%），瞬移 + 环射 14 发。
- 节奏：区域封锁，逼玩家走位。

### 11.4 腐母（第 4 层）

- HP 2350 / 半径 64 / 接触伤害 20
- 阶段 1：种子散射（8 发追踪孢子的抛物线）→ 毒新星（半径 220，延迟 1.0 s）。
- 阶段 2：召唤 2 只孢囊 + 藤蔓墙（3 道可破坏障碍），每 5 s 全屏毒雨。
- 节奏：持续召唤 + 场地污染。

### 11.5 虚空之主（第 5 层）

- HP 3150 / 半径 62 / 接触伤害 20
- 阶段 1：虚空环（3 圈交错弹幕）→ 瞬移三连砸（每次落点预警 0.55 s）。
- 阶段 2：引力场（把玩家拉向中心 1.8 s）→ 中心激光十字。
- 阶段 3（30% 以下）：镜像分身 2 个（30% HP，只放弹幕），本体螺旋弹幕密度 +50%。
- 节奏：从读招转为极限走位。

### 11.6 回响守卫（隐藏层，第 6 个 Boss）

- HP 1700 / 半径 50 / 接触伤害 17
- 招式：复制玩家当前武器（镜像连射）、护盾球环绕、突进斩三连。
- 意图：作为隐藏层的「镜子关」，考验玩家对自己武器的理解。

### 11.7 回响原型（隐藏 Boss）

- HP 4300 / 半径 66 / 接触伤害 22
- 阶段 1：三系弹幕轮换（火/冰/雷各 8 s），每系有独立弹型。
- 阶段 2：召唤 2 个玩家角色的镜像（使用角色技能）。
- 阶段 3（25% 以下）：全屏弹幕 + 收缩安全区（半径从 420 收到 150）。
- 奖励：真结局 + 大量金币 + 解锁「回响之刃」纪念记录。

## 17. 音频设计

| 类别 | 实现 |
| --- | --- |
| 射击 | 按弹道族区分：单发方波短促、散射噪声+低频、激光锯齿长音、蓄力上滑正弦、爆炸低频噪声 |
| 命中 | 高通噪声 0.045 s；暴击追加高频正弦 |
| 受击 | 锯齿下坠 + 噪声；同时触发 70 ms 振动（移动端） |
| 拾取 | 双音上行正弦 |
| 开门/传送 | 低频正弦 + 噪声扫频 |
| Boss 进场 | 55→120 Hz 锯齿 1.2 s |
| 音乐 | 分层程序化：bass（三角）+ 琶音（三角）+ hi-hat（噪声）；5 层不同 tempo/root，Boss 模式 tempo 加密一倍 |

音量：master 0.9，音效 0.5，音乐 0.13；同名音效最小间隔 20–120 ms 防噪音墙。

## 18. 美术规范

- 全部实时 Canvas 绘制：房间地板用离屏 canvas 烘焙（砖缝、裂纹、主题装饰、暗角），只保留当前房间一张。
- 角色：圆身 + 差异化头饰/披风 + 枪械朝向；受击闪白、无敌闪烁、护盾环、蓄力环。
- 敌人：基础形状族（史莱姆/漂浮/兽形/机械/盾牌/昆虫/祭司/巨像）+ 颜色/大小/发光区分；精英外环；词缀色描边。
- Boss：更大体型 + 独立轮廓 + 招式预警（地面圈、射线、线框、落点）。
- 子弹：加色混合（lighter），拖尾 + 核心白点；爆炸用径向渐变 + 冲击环。
- UI：深色底 + 主题强调色；按钮圆角；血条分段；小地图 7×7 格。
